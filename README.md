# Tempo Trainer — датчик темпа гольф-свинга

Две части: прошивка датчика (`firmware/`) и приложение-тренажёр (`app/`).

## 1. Железо

- **Seeed XIAO nRF52840 Sense** — плата с IMU (LSM6DS3) и Bluetooth, ~21×18 мм.
- **LiPo аккумулятор 3.7 В, 100–150 мАч** — припаять к контактам BAT+ / BAT− на нижней стороне платы (есть встроенная зарядка через USB-C).
- Кнопка/выключатель — по желанию. Можно просто вытаскивать аккумулятор.
- Корпус: термоусадка или напечатанный на 3D-принтере. Крепление: в торец грипа (высверлить заглушку) или на тыльную сторону перчатки на липучке.

Для первого теста аккумулятор не нужен — плата питается от USB-C с ноутбука/павербанка.

## 2. Прошивка

1. Установите Arduino IDE 2.x.
2. **File → Preferences → Additional boards manager URLs**, добавьте:
   `https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json`
3. **Boards Manager** → установите **Seeed nRF52 mbed-enabled Boards**.
4. **Library Manager** → установите **ArduinoBLE** и **Seeed Arduino LSM6DS3**.
5. Откройте `firmware/tempo_sensor/tempo_sensor.ino`, выберите плату *Seeed XIAO nRF52840 Sense*, порт, нажмите Upload.
6. Светодиод мигнёт 3 раза — датчик готов и виден по Bluetooth как **TempoSensor**.

Если плата не определяется — дважды быстро нажмите кнопку Reset на плате, она войдёт в режим загрузчика.

### Настройка порогов (вверху файла)

| Константа | Что это | Клюшка | Кисть |
|---|---|---|---|
| `START_DPS` | начало замаха, °/с | 40 | 30 |
| `IMPACT_G` | порог удара, g | 6 | 3.5 |
| `STILL_MS` | пауза в адресе, мс | 400 | 400 |

Откройте Serial Monitor (115200) — после каждого свинга печатается строка `замах,удар,пик_g×10`. По ней подбираете пороги.

## 3. Приложение

Откройте `app/tempo-trainer.html` в **Chrome** (Android или компьютер; на iPhone — браузер Bluefy).
Файл можно просто открыть двойным кликом, сервер не нужен.

- **Подключить датчик** → выбрать TempoSensor.
- После каждого удара: крупная цифра темпа, голосом по-русски, вердикт относительно эталона.
- **Эталон** — ваши замах/удар в мс. Кнопка «Эталон из последних 5» берёт среднее.
- **Метроном** — три щелчка (старт, вершина, удар) под эталон, повторяются; машите под него.
- **Демо** — имитация ударов, чтобы посмотреть приложение без железа.
- **Скопировать CSV** — история в буфер обмена для анализа.

История и эталон сохраняются в браузере.

## 4. Как детектируется темп

1. Клюшка неподвижна ≥400 мс → датчик взведён.
2. Угловая скорость > 40 °/с → старт замаха, запоминается доминирующая ось гироскопа.
3. Знак этой оси меняется → вершина замаха.
4. Ускорение > 6 g → удар.
5. Отправка `B,D,G` по BLE, 1.5 с пауза.

Свинги длиннее 2.5 с или удары дольше 0.9 с отбрасываются как ложные.

## 5. Что дальше

- Вибромотор на плате вместо голоса (пин D1 + транзистор) — чтобы работало без телефона.
- Сохранение в облако и привязка к рейтингу лиги.
- Второй датчик на кисть — тогда видно, кто «спешит»: руки или клюшка.
